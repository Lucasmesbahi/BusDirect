# BusDirect

Application web de gestion des réservations de places de bus développée en HTML5, Tailwind CSS et JavaScript. Le projet consiste à faciliter la gestion des passagers et des places disponibles pour le trajet **Safi → Marrakech**.

## Description du projet

L'objectif est de permettre à un agent de réservation de gérer les places du bus, de suivre les réservations et de consulter les places disponibles ainsi que le chiffre d'affaires.

L'application comprend un plan du bus avec 20 sièges et trois formulaires permettant de réserver, modifier et supprimer une réservation. Les données sont sauvegardées dans le navigateur à l'aide de LocalStorage.

## Fonctionnalités

1. **Plan du bus** : affichage des 20 sièges avec leur état.
2. **Réservation** : ajout d'un passager et attribution d'un siège.
3. **Modification** : modification du nom du passager ou de son siège.
4. **Suppression** : annulation d'une réservation et libération du siège.
5. **Places disponibles** : affichage du nombre de sièges libres.
6. **Chiffre d'affaires** : calcul du montant total des réservations.
7. **Notifications** : confirmation des opérations réussies.
8. **Sauvegarde des données** : conservation des réservations dans le navigateur avec LocalStorage.

## Objectifs du projet

- Créer une interface de gestion des réservations de bus.
- Structurer le contenu avec HTML5.
- Concevoir une interface responsive avec Tailwind CSS.
- Manipuler le DOM avec JavaScript.
- Gérer les événements et les interactions utilisateur.
- Ajouter, modifier et supprimer des réservations.
- Mettre à jour dynamiquement les places disponibles et le chiffre d'affaires.
- Sauvegarder les données avec LocalStorage.
- Améliorer l'expérience utilisateur grâce aux notifications.
- Organiser le projet et gérer les versions avec Git et GitHub.

## Installation

1. Cloner le dépôt GitHub.
2. Ouvrir le projet dans Visual Studio Code.
3. Ouvrir `index.html` dans un navigateur ou utiliser l'extension Live Server.
4. Utiliser les formulaires pour tester les différentes fonctionnalités.
